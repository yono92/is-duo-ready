# Security

보안 취약점은 [GitHub 비공개 취약점 신고](https://github.com/yono92/is-duo-ready/security/advisories/new)로 알려주세요. 공개 이슈에 비밀번호, 토큰, 개인정보 또는 악용 가능한 상세 내용을 올리지 마세요.

Please use GitHub's private vulnerability reporting for security issues. Include affected versions, a minimal reproduction, expected and actual behavior, and impact. Redact credentials and personal data. Only the latest main branch is maintained; no response-time guarantee is offered.

Local development credentials are disposable local defaults. Never reuse them in Production. Production DB/Auth/Storage access belongs in private environment configuration, not the repository.
