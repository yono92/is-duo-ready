# 008 — 자동 광고 운영 활성화

2026-11-02 사용자 명시 요청: 자동 광고를 실제 운영에 연결한다. 기존 001의 코드 준비와
구분하여 기존 Vercel/AdSense 프로젝트의 설정·배포를 허용한 후속 운영 범위다.

- 공개 ko/en 개인정보 안내와 푸터 링크를 제공한다. 실제 코드로 확인한 언어·테마·제보·
  관리자 인증 및 Google 광고 처리를 설명하고, 미확인 보관 기간·개인 연락처를 만들지 않는다.
- 정책 페이지에는 광고·동의 메시지 태그가 없어야 한다. 이미 광고를 연 공개 페이지에서
  정책·관리자·제보·빈 결과·오류로 이동해도 이전 문서의 광고 코드가 남지 않아야 한다.
- 기존 자동 광고 형식은 유지하고 ko/en admin/submit/privacy/methodology를 제외한다.
- 게시된 동의 메시지의 정책 URL을 공개 HTTPS 개인정보 안내로 연결한다.
- 기존 운영 환경의 ADSENSE_AUTO_ADS_ENABLED만 활성화하고 검증한 고정 소스를 배포한다.
- 승인 전에는 광고가 실제 송출되었다고 주장하지 않는다. 심사/ads.txt 상태와 코드·설정
  완료를 구분한다. 새 프로젝트·DB 변경·다른 콘텐츠 작업은 포함하지 않는다.

## 크롤링 및 동의 진단 후속 — 2026-11-02

사용자 요청에 따라 검색 색인 비활성은 유지하면서, 자동 광고가 활성화된 실제 운영에만
정확한 `/ads.txt` 경로와 Google 광고·사이트 확인 크롤러의 공개 콘텐츠 접근을 허용한다.
관리자/API 제외와 로컬·fixture·Preview 경계는 유지한다. 일반 검색 크롤러의 전체 콘텐츠
접근을 허용하거나 검색 색인 플래그를 켜지 않는다. 배포 후 ads.txt 계정 재확인 및 공식
강제 동의 테스트를 수행하고, 관찰된 오류·제공자 응답과 미확인 원인을 구분한다.

## 콘텐츠 정책 반려 대응 — 2026-11-13

사용자가 제공한 계정 화면의 사유는 ‘게시자 콘텐츠가 없는 화면에 Google 게재 광고’다.
사용자는 가능한 수정을 진행하도록 요청했다. 반려된 개별 URL이나 Google의 내부 판단은
확인되지 않았으며 자체 점검과 승인 여부를 구분한다.

- 실제 데이터 여부만으로 광고를 허용하지 않는다. 앱 상세는 언어별 정확한 경로와 자체
  콘텐츠 검토 이유를 명시적으로 등록한 경우에만 기존 운영 게이트를 통과할 수 있다.
- 홈·검색·필터·페이지 이동 결과와 최근 변경 목록에는 광고 로더를 넣지 않는다.
- 지금은 검토 완료한 광고 허용 페이지가 없으므로 목록을 비워 자동 광고를 보류한다.
  지원 상태·글자 수·앱 수를 광고 적합성의 자동 판정 기준으로 사용하지 않는다.
- 소유권 메타·ads.txt·심사 봇 접근과 기존 광고 문서 격리는 유지한다.
- 한영 지원 안내에 근거의 범위·버전 차이·미확인·공식 정보와 실사용 구분·제보 방법을
  보강한다. 가짜 지원 근거·실기기 경험·검토일은 추가하지 않는다.
- 코드 검증, 운영 반영, 콘텐츠 적합성 및 Google 재심사 결과는 각각 구분해 기록한다.
