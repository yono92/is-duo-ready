# 008 — 자동 광고 운영 활성화

2026-11-02 사용자 명시 요청: 자동 광고를 실제 운영에 연결한다. 기존 001의 코드 준비와
구분하여 기존 Vercel/AdSense 프로젝트의 설정·배포를 허용한 후속 운영 범위다.

- 공개 ko/en 개인정보 안내와 푸터 링크를 제공한다. 실제 코드로 확인한 언어·테마·제보·
  관리자 인증 및 Google 광고 처리를 설명하고, 미확인 보관 기간·개인 연락처를 만들지 않는다.
- 정책 페이지에는 광고·동의 메시지 태그가 없어야 한다. 이미 광고를 연 공개 페이지에서
  정책·관리자·제보·빈 결과·오류로 이동해도 이전 문서의 광고 코드가 남지 않아야 한다.
- 기존 자동 광고 형식은 유지하고 ko/en admin/submit/privacy/methodology를 제외한다.
- 게시된 동의 메시지의 정책 URL을 공개 HTTPS 개인정보 안내로 연결한다.
- 기존 운영 환경의 ADSENSE_AUTO_ADS_ENABLED만 활성화하고 검증한 고정 소스를 배포한다.
- 승인 전에는 광고가 실제 송출되었다고 주장하지 않는다. 심사/ads.txt 상태와 코드·설정
  완료를 구분한다. 새 프로젝트·DB 변경·다른 콘텐츠 작업은 포함하지 않는다.
