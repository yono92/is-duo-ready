# 구현·릴리스 계획

1. messages의 ko/en 안내, `/privacy` 서버 페이지와 SEO·푸터 링크를 추가한다.
2. 운영 opt-in이 켜졌을 때 AdNavigation으로 같은 사이트의 페이지/쿼리 이동을 문서 이동으로
   처리한다. 해시·외부 링크·새 탭·키보드 조작은 유지한다. 검색/필터는 목록 앵커로 이동한다.
   fixture·로컬·Preview의 기존 클라이언트 탐색은 유지한다.
3. 기존 계정의 자동 광고를 유지하면서 8개 제외 prefix를 저장한다. 정책을 먼저 배포하고
   공개 페이지를 확인한 뒤 동의 메시지 URL을 연결한다. 운영 flag는 마지막에 활성화한다.
4. lint/typecheck/unit/E2E/build 및 공개 운영 브라우저에서 광고 로더·무광고 정책 페이지·
   관리자/제보/빈 결과 이동을 확인한다. 실제 광고를 클릭하지 않는다.
5. 기존 체크아웃의 병행 변경을 제외한 커밋/고정 소스를 사용하고 배포 ID·복구 대상·
   계정 상태·미검증 영역을 docs/verification.md와 docs/adsense.md에 기록한다.

6. 후속 크롤링 점검: 자동 광고의 기존 운영 게이트를 robots에도 사용한다. 검색 미허용
   wildcard에는 `/ads.txt$`만 예외로 두고, 광고·사이트 확인 전용 봇에는 기존 공개 경로
   규칙을 명시한다. 검색 색인 메타·sitemap·관리자 차단과 비운영 차단을 검증한 뒤 배포한다.
   계정 재확인 및 공식 강제 동의 테스트를 수행하며 Google 처리 지연과 실제 오류를 구분한다.
