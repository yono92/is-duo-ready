# 007 데이터 정합성과 공개 집계

2026-10-30 사용자 요청: DB 정합성을 우선하고 WorksOnDuo의 전체/상태별 수 표시를 참고한다.
기존 1,000개 상한을 유지한다. 판정 기준은 PRD와 기존 공식 근거 정책이며 외부 사이트의
Built for Duo/Full screen 등 분류를 자체 판정으로 가져오지 않는다.

## P1: 반복 가능한 구조 검사

운영 DB를 읽기 전용·동일 스냅샷에서 검사한다. 앱 ID/slug 중복, KR 목록/ID, 공개·비공개
경계, 공개 상태·근거·버전·번역·이력, 아이콘 메타데이터, 미래 시각, RLS/제약을 확인한다.
편집 초안의 차이·번역 fallback·역사적 근거는 오류와 분리한다. 데이터나 판정을 자동 정정하지 않는다.
규칙과 실행 결과를 보존하고 구조 검사와 새 공식 출처/실기기 검증을 구분한다.

독립 검증: 고의로 깨진 공개 스냅샷과 근거 누락을 발견한다. 편집 중인 비공개 변경이나
최신 릴리스 노트에서 사라진 과거 근거 때문에 공개 판정을 덮어쓰거나 지우지 않는다.

## P2: 공개 앱 집계

한국 스토어의 published 앱만 총수·supported/planned/unknown/unsupported로 집계한다.
상태들은 상호 배타적이며 합계는 총수와 같아야 한다. 내부 DB 1,000개와 공개 995개를
혼용하지 않는다. 검색·분류·상태·페이지를 바꿔도 전역 집계는 유지하고 결과 수만 달라진다.
집계·결과 수·페이지 보정·목록은 같은 SQL 문/스냅샷에서 읽는다. 오류·누락을 0으로 바꾸지 않는다.
ko/en, 라이트/다크, 모바일·키보드·fixture 차단을 유지한다. 개발 fixture 집계는 예시로 표시한다.

2026-10-30 시각 수정: 숫자 카드 대신 스토어·총수 한 줄, 상태별 실제 비율의 가로 막대,
아이콘·라벨·수를 나란히 둔 범례를 표시한다. 막대는 0개 상태의 폭을 만들지 않으며,
빈 모집단은 빈 트랙을 표시한다. 범례에는 0개 상태도 표시하고 모바일에서 줄바꿈한다.

사용자 승인 후속 수정: 실제 `@astryxdesign/vega`의 `VegaChart`로 가로 100% 누적 막대를
렌더한다. canary 패키지는 정확한 버전으로 고정하고 core 0.7.4를 유지한다. Astryx 데이터
시각화 색상을 막대와 범례에 동일하게 적용한다. 집계·범례는 서버에서 읽을 수 있어야 하며
차트 실패에서 개수·판정을 바꾸지 않는다. 반응형과 두 언어·테마·검색 독립성을 검증한다.

최신 선택: 일반 차트 라이브러리 비교 후 사용자가 Recharts 전환을 선택했다. VegaChart를
Recharts 가로 정규화 누적 막대로 교체하고 Vega 의존성을 제거한다. 정확한 버전 고정,
서버 집계·범례, Astryx 데이터 색상·툴팁 표면, 0개 상태 처리와 기존 검증 기준을 유지한다.

시각 완성도 후속 요청: Recharts를 유지한다. 공식 지원 수와 전체 대비 비율을 대표 숫자로
강조하고, 14px 막대·옅은 미확인 영역·정렬된 범례·개수/비율 위계가 있는 툴팁을 적용한다.
막대의 표시 영역은 32px로 유지하며 0개 상태와 실제 비율을 왜곡하지 않는다.

독립 검증: 초안 제외, 모든 상태의 합계, 0개 검색 결과, 마지막 페이지, 언어·모바일·접근성,
실제 운영 익명 역할의 집계와 기존 공개 내용 불변을 확인한다. UI 구현은 로컬이며 배포는 별도다.

사용자의 후속 명시 요청으로 위 공개 UI의 운영 배포를 승인했다. 현재 운영 프로젝트에
고정한 공개 소스를 올리고 검증한 production 빌드를 같은 운영 도메인으로 promote한다.
병행 중인 비공개 관리자 수정은 제외하며 DB·환경·배포 보호·Git 상태는 변경하지 않는다.

## P3: 전체 공식 문구 재조회 — 2026-10-30

사용자의 전체 재조회 요청에 따라 기존 1,000개 App Store ID를 고정하고 한국 Lookup의
최신 업데이트 내역·설명과 공개 제품 페이지에 포함된 과거 버전 내역을 수집한다. 조회한
ID·스토어·관측 시각·원문·버전·실패·기준 스냅샷 해시를 비공개 manifest에 남기고 재개한다.
다른 앱 추천과 사용자 리뷰, 일반 호환 기기 목록을 지원 근거로 사용하지 않는다.
후보 원문을 직접 검토하여 현재 지원 선언, 준비 표현, 단순 버그 수정, 기기와 무관한
동음어를 구분한다. 자료 부재로 기존 판정을 취소하거나 수집 시각을 검토일로 바꾸지 않는다.
이번 요청은 조사와 검토 자료 생성이며 공개 판정·DB 콘텐츠·스키마·배포는 자동 변경하지 않는다.
전체 과거 릴리스나 모든 개발사 사이트·실기기까지 확인했다는 주장은 하지 않는다.

## 최신 소스 배포·Git 동기화 — 2026-10-30

이후 사용자의 “지금 제일 최근걸로 바꿔” 지시로 최신 로컬 제품 소스의 운영 반영을 승인했다.
수동 배포 뒤 main 자동 배포가 미커밋 집계·Recharts 변경을 누락한 원인을 확인했다.
이전 배포의 관리자/Git 제외 범위보다 최신 사용자 지시를 우선해 검증한 현행 제품·도구·
테스트·명세를 main에 반영하고 같은 소스의 운영 배포를 확인한다. 운영 DB 콘텐츠·판정·
스키마·환경 값·배포 보호와 비공개 로컬 자료는 변경하거나 공개하지 않는다.

사용자 후속 요청에 따라 집계를 실제 Astryx Card 안에 묶는다. 지원 라벨·대표 수·비율과
