# 콘텐츠 품질과 광고 재심사 준비

2026-11-23 사용자 요청: AdSense 재신청 전에 콘텐츠 품질을 개선한다. 11-13 반려 사유는 ‘게시자
콘텐츠가 없는 화면에 Google 게재 광고’다. 공개 앱 1,745개 중 1,438개가 비슷한 문구의
‘지원 정보 없음’ 상세라는 점이 저가치·중복 콘텐츠 위험으로 남아 있다. 사용자는 0~3단계 전체
진행을 지시했다.

## 계약

1. **운영 코드와 main 일치**: 운영 배포 `dpl_ERsdHFD8akRtyFoJyswVy2hbNBCy`의 파일 해시와 같은 미커밋 코드를
   커밋한다. 이후 배포가 기존 광고 보류·세 분류 공개를 되돌리지 않아야 한다.
2. **소개 페이지** `/{locale}/about`: 운영 주체(GitHub 계정 yono92), Apple·개발사와 비제휴, 자료 수집 범위,
   하지 않는 일(실기기 테스트·미지원 판정·리뷰 해석), 갱신 기록, 정정·문의 창구를 한영으로 설명한다.
   개인정보처리방침의 기존 사실과 다르게 쓰지 않는다. 푸터에서 연결한다.
3. **갱신 리포트** `/{locale}/reports`, `/{locale}/reports/{YYYY-MM-DD}`: 실제 운영 갱신(11-20, 11-23)마다
   새로 확인한 지원 앱·원문 근거·지원 버전과 편집 분석(펼친 화면 활용 방식, 짧은 공지형 근거의 한계,
   지원으로 세지 않은 표현과 이유)을 제공한다. 앱 이름·링크는 공개 DB에서 조회하고, 비공개·보관 앱은 링크하지 않는다.
   수치와 앱 목록은 해당 갱신 기록·검토 manifest와 일치해야 하며 추정 수치를 만들지 않는다.
4. **앱 상세의 최근 확인 내역**: 해당 갱신의 실제 수집 결과로 확인 시각, 확인한 버전 기록 수와 결과를 보여 준다.
   결과는 기존 근거 재확인 / 현재 다른 공식 문구로 재확인 / 현재 원문에서 재확인 못함 / 듀오 언급 없음 /
   호환 기기 목록에만 있음 / 언급은 있으나 지원으로 판정하지 않음(일반 폴더블·버그 수정만·범위 불명·준비 중)이다.
   보류 문구는 원문 발췌·버전과 함께 표시한다. 이 내역은 지원 판정·검토일·근거를 바꾸지 않는다.
5. **같은 카테고리의 지원 확인 앱**: 앱 상세에서 같은 카테고리의 공개 지원 확인 앱을 최대 4개 연결한다.
6. **광고 허용 범위**: 광고 로더는 편집 검토 목록에 정확한 경로가 기록된 페이지에서만 허용한다.
   허용 가능한 경로 형식에 지원 안내와 갱신 리포트 상세를 추가한다. 홈·검색·목록·최근 변경·제보·
   개인정보처리방침·관리자·소개·리포트 목록은 계속 제외한다. 앱 상세는 이번 범위에서 허용하지 않는다.
7. **선택적 색인**: `PUBLIC_INDEXING=true`일 때도 ‘지원 정보 없음’ 앱 상세는 noindex로 두고 sitemap에서 뺀다.
   소개·리포트·지원 안내와 지원 확인·예정 상세만 색인 대상으로 한다. 환경 변수 전환은 사용자 결정이다.

## 제외

DB 스키마·RLS 변경, 지원 판정 변경, Google 재심사 요청(사용자 계정 작업), 검색 색인 환경 변수 전환,
운영 배포(사용자 확인 후 별도 진행).

## 검증

ko/en·light/dark·360/768/1440px·키보드·axe로 소개·리포트·상세 섹션을 확인한다. 광고 허용 경로·검토 목록·
fixture 차단 단위 검사, 리포트·확인 내역 데이터와 갱신 기록의 일치 검사, 색인/sitemap 규칙 검사,
lint/typecheck/unit/E2E/build를 수행하고 실제 결과를 기록한다.
