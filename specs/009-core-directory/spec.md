# 국내 주요 앱 중심 탐색

## 현재 계약: 통합 앱 탐색 — 2026-11-13

사용자가 목록 탭의 혼란을 줄이는 개선을 승인했다. 아래 계약이 2026-11-03 목록 분리 계약을 대체한다.

- 공개 KR 앱을 하나의 목록으로 보여 주고 검색·지원 상태·카테고리로 좁힌다. 목록 선택 탭은 제거한다.
- 기본 `sort=familiar`는 편집 선정 또는 저장된 최신 KR 전체 무료 상위 100위 앱을 먼저 표시한다.
  각 그룹에서 무료 차트 순위가 있는 앱은 순위순, 나머지는 표시 언어의 이름순이다.
  유료·장르 순위만으로 우선 그룹에 넣지 않으며 이용자 수·인지도·지원 확정 순위로 표현하지 않는다.
- 차트 테이블이 없을 때 편집 선정 여부와 이름순으로 대체한다. 모든 공개 앱을 유지하고 순위를 만들지 않는다.
- 기존 무료·유료 인기순, 공식 지원 우선, 최근 지원 변경, 이름순의 동작은 유지한다.
- 검색·상태·분류·정렬 변경은 나머지 조건을 보존하고 첫 페이지로 이동한다. 새 URL은 `collection` 없이 생성한다.
- 이전 `collection=core/all`은 통합 목록으로 해석한다. `collection=supported`는 유효한 명시적 상태가
  없을 때만 `status=supported`로 해석한다. `status=all`도 명시적 선택이며 검색어·분류·정렬·페이지를 보존한다.
- 검색을 먼저 배치하고, 지원 상태 버튼은 모바일·데스크톱 모두 항상 표시한다. 카테고리는 데스크톱
  사이드바·모바일 Astryx Dialog에 둔다. 검색 결과 수와 전체 통계 범위를 구분한다.
- 지원 통계는 전체 공개 KR 앱 기준으로 고정하며 검색·분류·상태와 독립적이다. 검색·필터 아래의
  Astryx Collapsible 안에 두고 처음에는 접어 둔다. 키보드로 열고 닫을 수 있어야 한다.
- `unknown`은 “근거 미확인” / “Unconfirmed”로 표시한다. 미지원 확정과 구분하며 데이터 판정·근거·검토일은 바꾸지 않는다.
- 기존 언어 전환, 테마, 페이지·상세 복귀·뒤로 가기, 모바일 레이아웃과 fixture 운영 차단을 보존한다.
- DB 스키마·운영 데이터·공개 권한·배포는 변경하지 않는다.

검증: 전체 앱 노출과 주요 앱 우선 정렬, fixture/SQL 일치, 차트 부재, 기존 URL 정규화·왕복,
검색/필터 보존, 전체 통계 분모, ko/en·360/768/1440px·테마·키보드·상세 복귀·뒤로 가기,
lint/typecheck/unit/E2E/build와 격리 DB 검사를 수행하고 실제 결과를 기록한다.

## 이전 계약 — 2026-11-03

2026-11-03 사용자 요청: 국내 주요 앱이 기본 목록에 먼저 보이도록 바꾸고, 공식 듀오
지원 확인 앱을 별도로 탐색하며 나머지 공개 앱도 검색으로 찾을 수 있게 한다.

- 기본 `collection=core`: 편집 선정한 국내 생활·쇼핑·금융·이동·콘텐츠·업무 앱과
  저장된 최신 KR 전체 무료 top 100에 포함되는 공개 앱의 합집합이다. 유료·장르
  순위만으로 기본 목록에 편입하지 않는다. 국내 이용자 수/인지도 순위라고 주장하지 않는다.
- `collection=supported`: 기존 공식 지원 판정 앱만 표시한다. 근거·판정·검토일은 바꾸지 않는다.
- `collection=all`: 모든 공개 KR 앱을 유지한다. 새 검색 제출은 전체 목록으로 전환한다.
  직접 공유한 명시적 collection URL의 검색 범위는 보존한다.
- 목록 선택은 URL·페이지·언어·상세 복귀에 보존한다. 선택을 바꾸면 검색·상태·분류·페이지를 초기화한다.
- 주요 앱 목록의 인기 정렬은 순위를 우선한다. 다른 목록의 기존 지원 우선 정렬은 보존한다.
- 지원 통계는 선택 목록 전체 기준이며 검색·카테고리·상태와 독립적이다. 집계 범위를 명시한다.
- 추가 DB 스키마·공개 권한 변경, 앱 삭제, 운영 배포는 필요하지 않다.

검증: 인기 목록과 선정 앱의 합집합, 지원 목록 독립성, 전체 검색, URL 왕복, 검색 외 통계
분모, 익명 SQL/RLS·페이지 경계·차트 부재, ko/en·모바일·키보드 탐색을 확인한다.
