# 010 지원 조사 내역과 실사용 제보

사용자 승인: 2026-11-13. 주요 앱 50개의 개발사 공식 자료 보강, 조사 내역 공개,
실사용 제보 확장을 구현한다. 기존 네 가지 공식 지원 상태와 근거 판정은 유지한다.

- 기존 주요 앱 중 공개·unknown 50개를 편집 표본으로 선정한다. 이용자 순위로 주장하지 않는다.
- 실제 관측한 공식 URL·범위·시각·결과를 기록한다. 기존 App Store 관측을 재사용할 때 원래
  관측 시각을 유지한다. 접근 실패·미조사·명시적 문구 미발견을 구분한다. 원문을 읽지 않은
  검색 결과와 공식 도메인의 사용자 글은 공식 판정 근거가 아니다.
- 실제 공개 앱 상세에 조사 내역과 다음 제보 동선을 제공한다. 기록이 없으면 미조사로 안내한다.
- 실사용 제보는 기기/시뮬레이터, 기기명, OS·앱 버전, 관찰일, 화면 상태, 동작 결과,
  본문과 선택 스크린샷 1장을 받는다. 자료 URL은 실사용 제보에서 선택이다.
- 제보자는 검토 후 내용·버전·이미지 공개에 동의한다. 개인정보 제거를 안내한다.
  원본 제보·검토 사유·미승인 이미지는 비공개이고 관리자 권한을 서버와 RLS로 확인한다.
- 승인한 실사용 제보는 별도 공개 관찰 기록이다. 공식 지원·근거·지원 검토일을 바꾸지 않는다.
  앱 보관 시 공개 관찰·이미지도 감추며, 관리자는 공개를 철회할 수 있다.
- 기존 추가/정정 제보, 승인, rate limit, fixture 운영 차단, ko/en, 테마·키보드·모바일을 보존한다.

완료 검증: 실제 50개 조사 기록의 신원·URL·시각 검토, 미조사/실패 표시, 이미지 검증,
익명 제보→비공개 검토→승인 공개→철회 흐름과 권한·공식 판정 불변, 필수 제품 검사.
