# 부분 대응 상태

2026-11-23 사용자 결정: itsub.cc/forduo(빌드 SDK 기준 세 단계 표시)와 대조한 뒤 호환 정책을 덜 엄격하게
운영한다. SDK 기준 판정은 보류한다. 공식 출처가 iPhone Duo를 직접 언급하지만 대응 범위가 불명확한 경우를
`unknown`으로 숨기지 않고 새 공개 상태 **부분 대응** / **Partial support**(`partial`)로 공개한다.

## 계약

1. **상태 정의**
   - `supported` 지원 확인: 공식 출처가 Duo 지원·최적화 또는 Duo 전용 화면·기능을 명시한다.
   - `partial` 부분 대응: 공식 출처가 iPhone Duo를 직접 언급한 개선·대응을 밝히지만 지원 범위나 화면·기능이
     불명확하다. 예: “iPhone Duo 사용성 개선”, “iPhone Duo 환경 사용성 개선”.
   - `planned` 지원 예정, `unknown` 지원 정보 없음은 기존 정의를 유지한다.
2. **유지하는 원칙**: 일반 폴더블·태블릿·화면 크기 문구, ‘Solo/Duo’ 같은 무관한 용어, 호환 기기 목록 표시,
   Duo 관련 버그 수정만 있는 노트, 스크린샷 추가만 있는 노트는 `partial`의 근거가 아니다. 제3자 사이트(itsub 등)는
   발견 경로이며 근거가 아니다. `partial`도 `supported`와 같이 확인된 공식 근거가 필요하다.
3. **공개 표시**: 배지·필터·집계·분포 차트·지원 안내·관리자 상태 선택·변경 이력에 `partial`을 표시한다.
   공개 순서는 지원 확인 → 부분 대응 → 지원 예정 → 지원 정보 없음이다. 요약은 범위가 불명확하다는 점을 밝힌다.
4. **색인**: `partial` 상세는 공식 근거가 있으므로 `supported`·`planned`와 같이 색인·sitemap 대상이다.
5. **DB**: `app_support.status` CHECK에 `partial`을 추가하는 마이그레이션. 공개 스냅샷의 근거 필수 규칙과
   콘텐츠 품질 검사는 `partial`에도 적용한다. 기존 행은 바꾸지 않는다.
6. **데이터 반영**: 운영 반영은 별도 사용자 승인 후 기존 dry-run/apply 절차로 한다. 이번 범위에서는 재조사
   기록과 반영 후보 manifest까지만 만든다.

## 제외

SDK·바이너리 분석, 제3자 데이터 복제, 운영 DB 쓰기·배포, 사용 경험의 판정 반영.
