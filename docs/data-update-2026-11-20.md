- 이전 ‘지원 안 함’ 분류는 렌더링되지 않음
- 신규 공개 132개와 기존 지원 정정 12개의 아이콘 144개가 저장된 SHA-256과 일치
- 보관 7개의 아이콘은 모두 404
- 보관 7개의 한영 상세는 not-found·noindex 화면이며 앱 정보 없음

최종 독립 DB·운영 HTTP 검사는 각각 첫 실행에서 통과했다.

## 제품 검사

제품 코드는 바꾸지 않았고, 제품 검사는 오늘 새로 실행했다.

- `npm run lint`: 통과. 기존 `.data` 파일 경고 3개, 오류 0개.
- `npm run typecheck`: 통과.
- `npm test`: 22개 파일, 127개 통과.
- `npm run test:e2e`: 첫 실행은 테스트 시작 전 실패했다. 설치된 Next.js 16.4.3의 개발 서버가 알려진 보안 취약점 영향 안내를 출력하고 종료했다. 같은 명령의 재실행에서 Chromium 45개가 통과했다.
- `npm run build`: 첫 실행은 같은 Next.js 보안 안내(`SecurityFatalError`)로 중단됐다. 재실행에서 기본 Turbopack 빌드가 통과했다. 기존 아이콘 저장소 동적 경로 tracing 경고는 유지된다.

Next.js 보안 안내는 이번 데이터 변경과 무관한 의존성 상태다. 업그레이드는 수행하지 않았다. 실제 명령의 종료 코드와 로그는 `.data/refresh-2026-11-20/checks/`에 있다.
