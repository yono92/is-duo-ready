## 실행 및 확인

대상 399개는 반영 직전 한국 API 조회에서 모두 검토 때와 같은 현재 버전을 반환했다.
운영 백업과 dry-run을 거쳐 기존 저장·공개 경로 및 메타데이터 갱신을 한 DB 트랜잭션에서 적용했다.
같은 배치 재실행 결과 신규 등록·지원 정정·버전·아이콘 변경이 모두 0건이었고
콘텐츠 테이블 16개의 해시가 일치했다.

독립 읽기 검사에서 공개 앱 1,305개, 공식 지원 245개, 갱신 대상의 원문·버전·한영 요약,
기존 앱 버전 변경 381개를 대조했다. 익명 역할의 비공개 앱 행·아이콘·이력 조회는 각 0건이었다.
운영 한영 전체 집계와 지원 앱 29개의 상세, 버전만 갱신한 3개 표본의 한영 상세를 포함한
HTML 66개를 확인했다. 지원 앱 아이콘 29개 모두 응답 바이트의 SHA-256이 저장값과 일치했다.

정합성 25개 규칙에서 오류는 0건이다. 의료 분류 경고 5개와 최신 API 노트 밖의
과거 릴리스·설명 인용 경고 108개를 기록했다. 이번 배치 코드 ESLint와 diff 검사를 통과했다.
제품 코드는 같은 날 [재검토에서 실행한 검사](verification.md)로 확인했다.

비공개 기준·백업·검토 manifest와 dry-run/apply/repeat, 독립 검증·운영 응답 기록은
`.data/apply-2026-11-09/`에 있다. 반영 후 운영 검증 시각은 한국 시간 08:56이다.
