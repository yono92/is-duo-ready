## 제품 검사

제품 코드는 바꾸지 않았고, 제품 검사는 오늘 새로 실행했다.

- `npm run lint`: 통과. 기존 `.data` 파일 경고 3개, 오류 0개.
- `npm run typecheck`: 통과.
- `npm test`: 22개 파일, 127개 통과.
- `npm run test:e2e`: 첫 실행이 테스트 시작 전에 실패했다. 설치된 Next.js 16.4.3 개발 서버가 보안 취약점 영향 안내를 출력하고 종료했기 때문이다. 같은 명령으로 다시 실행하자 Chromium 45개가 통과했다.
- `npm run build`: 첫 실행이 같은 안내(`SecurityFatalError`)로 중단됐다. 재실행에서 기본 Turbopack 빌드가 통과했다.

Next.js 보안 안내는 11-20부터 이어진 의존성 상태이며 업그레이드는 수행하지 않았다. 종료 코드와 로그는 `.data/refresh-2026-11-23/checks/`에 있다.
