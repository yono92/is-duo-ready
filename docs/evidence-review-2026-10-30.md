## 조회 범위와 결과

- 기준: 운영 등록 1,000개(공개 995개, 초안 5개)의 고정 App Store ID. 조회 국가는 KR.
- 최신 Lookup: 1000/1,000개 성공. 업데이트 내역과 앱 설명을 함께 확인했다.
- 제품 페이지: 1000/1,000개 성공, 최종 실패 0개.
- 제품 페이지에 포함된 버전 기록 19,692건을 확인했다. 앱별 최대 25개이며 전체 출시 이력은 아니다.
- 추가 지원 근거 후보: **90개**. 공개 앱 후보 90개.
- 지원 예정 후보: **1개**. 제공 중으로 확정하지 않았다.
- 기존 지원 74개는 유지했다. 기존 정확한 근거 발췌를 현재 설명/노트/페이지 버전 기록에서 다시 관측한 앱은 74개다.

한국 공식 발표를 함께 대조했다. 일반 호환 기기 목록에 Duo가 있다는 사실, 사용자 리뷰,

확인된 항목은 지원 버전을 만들지 않았다. 표는 대표 출처 하나이며 중복 근거는 비공개 검토 자료에 있다.

## 원본 기록과 반복 실행

원본은 기존 정책대로 Git 제외 파일에 0600으로 보존한다.

- 기준 DB 스냅샷: `.data/evidence-rescan-2026-10-30/baseline.json`
- 최신 조회: `docs/data/evidence-rescan-2026-10-30.json`
- 제품 페이지: `docs/data/evidence-pages-2026-10-30.json`
- 앱별 후보 원문·보류 사유·기존 근거 재관측: `.data/evidence-rescan-2026-10-30/review.json`
- Apple 한국 공식 자료의 URL·응답 상태·관측 시각·HTML 해시: `.data/evidence-rescan-2026-10-30/supplement.json`

```sh
node --import tsx scripts/rescan-app-evidence.ts --baseline=.data/evidence-rescan-2026-10-30/baseline.json --source=docs/data/evidence-rescan-2026-10-30.json
node --import tsx scripts/rescan-app-pages.ts --baseline=.data/evidence-rescan-2026-10-30/baseline.json --source=docs/data/evidence-pages-2026-10-30.json
```

같은 파일은 성공한 앱을 건너뛰고 실패·미완료만 재개한다. 새로운 전체 조회에는 새 기준
스냅샷과 새 날짜/실행 식별자의 출력 파일을 사용한다. 자동 판정·DB 쓰기·상시 스케줄러는 없다.
모든 개발사 웹사이트·전체 과거 릴리스·실기기·실제 제품 페이지 배지의 시각 검증을 완료한 것은 아니다.
