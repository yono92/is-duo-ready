## 검증 및 재현

운영 익명 역할에서 초안·보관 10개의 공개 행·아이콘·지원 이력은 각각 0개다.

현재 목록 계약대로 전체 앱을 명시한 재검사에서 일치했다. 집계 오류나 데이터 변경은 아니었다.

lint는 오류 0·기존 경고 3, typecheck 및 단위 100개가 통과했다. 전체 Chromium E2E는
37개 중 36개 통과·상세 이동 시나리오 1개 타임아웃이었고, 원본 그대로 집중 재실행한 1개는 통과했다.
기본 Turbopack 빌드는 process/port EPERM으로 두 번 실패했으며, 설치된 Next.js 문서의
`npm run build -- --webpack`은 통과했다. 제품·테스트 소스는 변경하지 않았다.

비공개 재현 자료는 `.data/fullscan-2026-11-04/`에 보존했다. 기준 DB·콘텐츠 백업·테이블 해시,
