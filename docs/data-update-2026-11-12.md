## 메타데이터와 공개 범위

기존 공개 앱 1,304개의 정상 수집 결과를 기록하고 현재 버전 335개를 갱신했다. 릴리스 노트 차이는 179개이며 버전 변경 대상과 겹친다. 지원 정정 대상 외에는 지원 상태·지원 버전·요약·검토일·이력을 보존했다. 수집 중 잠글시간의 API 2.45.0과 페이지 2.46.0 차이는 개별 API 재조회에서 2.46.0을 확인해 해소했다. 최초 수집과 재조회 원본을 모두 보존했다.

Brim은 같은 App Store ID에서 API와 페이지가 모두 Sidefill: Safari용 화면 끝까지 브라우징을 반환했다. 한영 표시 이름을 갱신하고 기존 이름을 검색 별칭으로 추가했다. 상세 주소·지원 근거·검토일·요약은 유지하며 Brim과 Sidefill 모두로 검색되는지 확인했다.

Ship Finder는 일괄·개별 및 반영 직전의 정상 한국 Lookup notFound와 제품 페이지 404를 확인해 공개 목록에서 제외했다. 이는 공식 미지원 판정이나 영구 판매 종료 주장이 아니다. 기존 앱·근거·아이콘·이력은 비공개로 보존했다. 신규 Essential Anatomy 5와 Human Anatomy Atlas 2027은 의료 분류 미매핑으로 비공개 초안이다.

신규 172개와 기존 지원 정정 7개의 아이콘을 기존 원본 검증·비공개 Storage 경로로 저장했다. 기존 공개 앱의 아이콘 URL 차이 597개 전체를 교체한 작업은 아니다. 아이콘 URL 차이를 디자인 변경으로 단정하지 않는다. 자산 정책은 [자산 기록](assets.md)을 따른다.

운영 순위 테이블은 아직 설치되지 않았다. 이번 차트는 신규 앱 선정과 발견 출처 기록에 사용했으며, 공개 인기순 표시를 새로 동기화하지 않았다. 스키마 변경·배포·상시 수집 활성화는 수행하지 않았다.
