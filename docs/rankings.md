# 메인 인기순 정렬

기본은 한국 App Store **전체 무료 인기순**이며 메뉴에서 유료 인기순, 공식 지원 우선,
최근 변경순, 이름순을 선택한다. 무료·유료 앱을 탭이나 가격 필터로 분할하지 않는다.
순위는 무료/유료 전체 차트 각각의 공식 1–100위 관측값이다. 카테고리를 선택해도
카테고리 차트 순위를 전체 순위와 혼합하거나 결과 안에서 1위부터 다시 매기지 않는다.
무료·유료 인기순 모두 **공식 지원 앱 전체 → 나머지 앱** 순서로 표시한다. 각 그룹에서는
차트 순위순, 순위 없는 앱은 이름/slug 순이다. 순위 없는 공식 지원 앱도 지원 미확인 1위
앱보다 앞선다. 순위 자료가 없으면 공식 지원 우선·그룹 내 이름순 대체를 안내한다.

`008_app_chart_rankings.sql`은 순위·공식 출처·차트 갱신 시각·수집 시각을 별도 테이블에
저장한다. 익명/일반 로그인 사용자는 공개 앱의 순위만 읽고, 쓰기는 관리자만 가능하다.
지원 상태·근거·검토일·공개 이력을 갱신하지 않는다. 페이지는 외부 차트를 직접 조회하지 않는다.
테이블 설치 전에도 목록은 대체 정렬로 작동하므로 007 컬럼 제거와 함께 호환 코드부터
배포할 수 있다. 운영 migration과 순위 동기화는 별도 릴리스 작업이다.
기존 앱·근거 콘텐츠 전송에는 순위 관측을 포함하지 않는다. 새 환경이나 복구 환경에서는
아래 동기화 CLI로 순위를 다시 연결한다. 이로써 순위 테이블이 아직 없는 운영 DB의
기존 백업·수집·지원 근거 반영 스크립트도 계속 사용할 수 있다.

## 수집 결과 연결

완료된 기존 차트 수집 manifest가 필요하다. CLI는 두 KR 전체 차트가 각 100건인지,
원본 URL·앱 ID·순서·시각·중복 여부를 검증한다. 장르별 차트는 이번 정렬에 사용하지 않는다.
등록된 앱 ID만 연결하고 새 앱/지원 상태를 만들지 않는다. 오래된 관측으로 덮어쓰기를
거부하며 두 차트 교체를 한 트랜잭션으로 처리한다. 기본은 dry-run/rollback이다.

로컬:

```sh
npm run db:migrate
node --import tsx scripts/sync-chart-rankings.ts --source=.data/refresh-2026-11-02/rank-manifest.json
node --import tsx scripts/sync-chart-rankings.ts --source=.data/refresh-2026-11-02/rank-manifest.json --apply
```

운영 dry-run은 기존 비공개 hosted 설정과 명시적 project ref를 사용한다:

```sh
node --import tsx scripts/sync-chart-rankings.ts --target=production --project-ref=yourprojectref --source=.data/refresh-2026-11-02/rank-manifest.json
```

실제 반영에는 `--apply`가 필요하다. `yourprojectref`를 실제 설정과 일치하는 값으로 바꾼다.
기본 순위 자동 갱신 스케줄은 이번 범위에 포함하지 않는다. 화면은 관측 수집일과 출처를
표시하며 현재 실시간 순위 또는 앱 지원 근거로 표현하지 않는다.

2026-11-02 로컬 검증: 실제 전체 무료/유료 각 100건 중 로컬에 등록된 앱 8/5개를 연결했다.
로컬 앱은 초안이므로 해당 순위는 익명 공개되지 않는다. 운영 1,181개 목록의 반영 결과나
화면은 이번 로컬 실행으로 검증한 것으로 주장하지 않는다. 브라우저 검증은 별도 격리 DB에서
명확한 가상 앱·순위를 사용했다. 자세한 실행 결과는 docs/verification.md에 기록한다.
