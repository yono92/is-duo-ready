# 데이터 정합성과 집계 기준

2026-10-30 요청에 따라 앱 수 확대보다 데이터 정합성과 근거 보강을 우선한다.
DB는 기존 1,000개를 유지한다. [WorksOnDuo](https://worksonduo.com/apps)는 상태별 수를
보여주는 구성의 참고이며 판정 출처가 아니다. 해당 사이트의 미국 스토어·화면 적응 분류를
우리의 한국 스토어·공식 근거 기반 판정과 동등하게 취급하지 않는다.

## 모집단과 수의 의미

- 내부 등록: `app_private.apps`의 앱 ID별 1행. 현재 1,000개이며 초안·보관을 포함한다.
- 공개 총수: `public.directory_entries`의 KR/published 앱. 현재 995개다.
- 공개 상태: 공식 지원 74, 지원 예정 0, 근거 미확인 921, 미지원 확인 0. 합계는 995다.
- 내부 미확인: 공개 921개와 의료 초안 5개를 합한 926개다. 미지원의 증거가 아니다.
- 검색 결과 수는 검색·카테고리·상태 필터에 따라 달라진다. 전역 집계는 공개 집합을 유지한다.

집계에는 초안 테이블을 읽는 우회 권한을 쓰지 않는다. 관리자 화면은 기존 공개/초안/보관
수로 내부 구성을 확인하며, 공개 홈페이지에는 공개 가능한 모집단만 표시한다.
SQL 집계·검색 수·페이지 보정·실제 목록은 한 문장에서 읽어 동시 공개 중의 시점 차이를 줄인다.
합계·음수·누락·소수 등 잘못된 수는 정상적인 0으로 처리하지 않는다. DB 오류 시 가상 통계로
대체하지 않는다. 개발 fixture의 수는 예시임을 표시한다.

## 검사 실행

```sh
npm run data:check
npm run data:check -- --target=production --project-ref=YOUR_EXISTING_PROJECT_REF
```

로컬 또는 기존 0600 hosted 설정의 DB에 연결한다. REPEATABLE READ READ ONLY로 검사하며
쓰기·공개·정정은 수행하지 않는다. 오류가 있으면 exit 1, 경고만 있으면 결과를 기록하고 정상
종료한다. 정해진 임계값이나 분포를 억지로 맞추지 않는다.

규칙 원본은 `scripts/lib/content-quality.ts`, CLI는 `scripts/check-data.ts`다. 규칙 코드 해시·
실제 DB 실행 시각·모집단·검사 결과를 `.data/quality/audit-*.json`에 0600으로 남긴다.
검사 기록은 Git에서 제외한다. 물리적인 아이콘 바이트와 새로운 공식 웹 출처/실기기를
모두 재검증하는 명령은 아니다. 원본 수집 시각과 감사 실행 시각을 구별한다.

25개 규칙은 중복·KR 정체성·공개 경계·공개 스냅샷·정식 근거/버전·원문 번역·이력·
아이콘 참조·미래 시각·RLS/제약 및 초안/번역/역사적 자료의 차이를 검사한다.
공개 스냅샷이 진실의 기준이다. 편집 중인 초안의 상태·버전·번역이 다르면 검토 대기 경고이며
공개 스냅샷으로 덮어쓰지 않는다. 공개 스냅샷에 보존한 evidence ID는 편집 과정에서 비공개
app_evidence 연결을 바꾸더라도 정상적인 공식 근거로 인정한다. 최신 노트에서 과거 발췌가
사라진 것만으로 지원을 취소하지 않는다. 별도 출처/버전 검토 후 기존 정정 절차를 사용한다.

## 실제 점검 결과와 남은 일

운영 점검은 오류 0건, 의료 분류 미완료 초안 5건의 경고였다. 공개 앱 ID·근거 연결·버전·
KR URL·번역·이력·RLS가 검사 범위에서 일치했다. 모든 실제 앱의 듀오 동작을 검증했다는
뜻은 아니다. 926개 미확인 앱의 공식 근거 보강과 의료 정식 분류는 별도 미완료 과제다.

최종 운영 감사 시각은 2026-10-30T00:34:01.674Z (UTC), 보고서는
`.data/quality/audit-1793320442034.json`이다. 규칙 코드 SHA-256은
`57800c29f7e977ae3003c598cd0f5a8834ccd6a3869776a6894daca4012a0bea`다.
실제 익명 역할의 SQL 대조는 `.data/quality/public-stats-verification.json`에 있다.
공개 995개/42페이지, 빈 검색 0개, 지원 74개/4페이지의 마지막 2개를 확인했고 모든 경우
전역 집계는 995/74/0/921/0으로 같았다. 운영 행·상태는 수정하지 않았다.

우선순위는 인기 앱의 공식 배지/개발사 문서/과거 릴리스 확인 → 원문·버전·관측 기록 확보 →
ko/en 검토 → 기존 공개/정정 트랜잭션이다. 근거를 확보한 앱만 판정을 바꾸며, 미확인을
미지원으로 일괄 변경하거나 수집 성공 시각을 사람의 최종 확인일로 사용하지 않는다.

홈 집계 UI는 로컬 구현이며 아직 배포하지 않았다. 운영 DB의 행·상태·스키마는 이번 작업에서
수정하지 않았다. 실제 검증 실행과 제한은 [검증 기록](verification.md)에 있다.
