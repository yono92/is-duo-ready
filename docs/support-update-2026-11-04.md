## 처리와 보존

현재 운영 콘텐츠 백업 → 근거·한영 요약 고정 → 반영 직전 한국 가용성 확인 → dry-run →

기존 원문 및 evidence ID·공개 근거·지원 확인 버전을 보존했다. 정정 대상 2개의 현재 버전과
