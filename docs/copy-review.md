검토일: 2026-10-29 (Asia/Seoul). 대상은 공개·관리자 화면에서 노출되는 제품 문구다.

양 언어 설명을 소비 화면 및 실제 처리 코드와 함께 검토했다. 앱 이름·개발사·공식 출처 인용 등
실제 등록된 앱 콘텐츠는 바꾸지 않았다.

## 적용 기준

- 화면 제목은 기능이나 내용을 직접 설명한다. 문장으로 된 안내는 사실을 `~습니다`, 행동을
  `~하세요`로 표현한다. 제휴 고지는 푸터에 한 번 표시한다.
- 검색 결과 없음, 페이지 오류, 정보 제공 불가를 구분한다. 공통 오류 화면은 목록뿐 아니라
  상세·제보·관리자에도 쓰이므로 “페이지를 불러오지 못했습니다”라고 표시한다.
- 네 지원 상태의 의미와 값은 보존한다. `unsupported`의 화면 이름만 “미지원 확인” /
  “Not supported”로 바꿨다. 공식 자료가 없다는 이유로 미지원으로 분류하지 않는다.
- 출처 수집 성공은 새 변경 발견을 보장하지 않는다. 가져오기는 진행·대기·완료 안내를
  구분한다. 초안 저장, 공개, 공개 중단은 각각의 결과와 다음 행동을 설명한다.
- 관리 화면의 “관측”, “감시”, “공개 목록에서 보관 처리”를 동작에 맞는 표현으로 바꿨다.
  CSV 열 이름·용량 제한·robots.txt 등 작업에 필요한 기술 조건은 유지한다.
- 공식 배지·자료 확인, 한국 스토어 기준, 번역 fallback, 기존 정보 보존과 비공개 제보 조건은
  유지한다. 출처 확인 체크박스는 확인한 사실을 명확하게 진술한다.
- 가상 앱 설명은 비유를 빼고 기능을 설명하며 가상임을 명시한다. 실제 지원 근거·날짜를
  생성하지 않는다. 기기 안내는 3D 예시임을 밝히고 실제 조작법을 설명한다.
- 가져오기 내역의 날짜와 처리 개수가 붙어 읽히던 곳에 구분자를 추가했다.

## 제거한 중복·미사용 안내

- 전용 `/updates`와 `/submit`이 대체한 Info 분기 및 003·005 기능 번호·준비 중 문구.
- 상세 화면의 반복 소개와 가상 앱 소개 단락. 기존 예시 배너와 예시 상태 표시는 유지.
- 사용하지 않는 테마 전환 라벨·이전 기기 이미지 설명·예시 보기 키.
- 수집 화면 하단의 주간 운영 지시.

직접 작성한 제보 주소 placeholder는 메시지 사전으로 옮겼다. 출처 문구와 DB 오류·상태 코드의
직접 노출 여부도 확인했으며, 오류와 상태는 기존 번역 또는 일반 오류 fallback을 사용한다.
Astryx가 제공하는 선택·날짜·파일·닫기·페이지 이동 라벨도 한국어 카탈로그와 기존 override를
통해 표시되는지 확인했다.

검증 명령과 실제 결과는 [검증 기록](verification.md)의 전 화면 문구 검토 항목에 기록한다.
