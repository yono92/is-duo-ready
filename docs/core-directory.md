노출되지 않는다. 차트 자료는 수집된 관측 시점 기준이며 실시간 순위라고 표시하지 않는다.

신규 수집은 빠진 국내 주요 앱이나 공식 지원 근거가 확인된 후보를 우선한다. 카테고리별
차트로 등록 총수만 늘리는 작업을 기본 운영 목표로 삼지 않는다. 기존 전체 목록은 전문 앱
발견과 검색에 계속 사용한다. 이 변경은 자동 수집 스케줄을 새로 만들거나 변경하지 않는다.

## 검색·정렬·통계

- 기본 진입은 국내 주요 앱이다. 새 검색 제출은 전체 앱 목록에서 수행한다.
- 명시적인 collection URL은 범위를 보존한다. 이름·영문명·별칭 검색과 기존 필터를 유지한다.
- 목록을 바꾸면 검색·분류·상태·페이지를 초기화하고 정렬은 유지한다.
- 국내 주요 앱의 인기순은 순위 우선이다. 다른 목록의 지원 우선 정렬은 유지한다.
- 통계는 선택한 목록 전체 기준이다. 검색·분류·상태 필터로 분모를 바꾸지 않는다.
- URL·언어·상세 복귀·브라우저 뒤로 가기와 모바일 필터를 유지한다.

않았다. 로컬 구현 결과이며 운영 화면에 반영됐다고 주장하지 않는다.
