# 통합 앱 목록과 주요 앱 우선 정렬 — 2026-11-13

국내 사용자에게 관련 있는 앱을 먼저 보여 주면서 모든 공개 KR 앱을 한 목록에서 탐색한다.
검색·지원 상태 필터를 중심에 두고, 주요 앱 선정과 지원 판정을 구분한다. 기존 공개 앱이나
지원 근거는 삭제하지 않는다. 2026-11-03의 세 목록 선택은 이번 통합 탐색 계약이 대체한다.

## 기본 정렬과 선정 기준

| 기본 정렬의 그룹 | 포함 기준 |
| --- | --- |
| 먼저 표시 | 편집 선정 앱 또는 저장된 최신 KR 전체 무료 상위 100위의 공개 앱 |
| 이어서 표시 | 그 외 모든 공개 KR 앱 |

기본 정렬은 `familiar`다. 각 그룹에서 무료 차트 순위가 있는 앱을 순위순으로 표시한 뒤
나머지를 표시 언어의 이름순으로 보여 준다. 선정 그룹 밖의 앱도 같은 목록의 페이지에서
계속 탐색할 수 있다. 무료·유료 인기순과 기존 공식 지원 우선·최근 지원 변경·이름순도 유지한다.

편집 목록은 `src/lib/directory/core-apps.ts`에서 안정적인 Apple ID로 관리한다. 현재 공개
카탈로그에서 생활·쇼핑·결제·은행·대중교통·지도·콘텐츠·소통·업무 용도를 대표하는 앱을
선정했다. 카카오톡·네이버·토스·쿠팡·배민·당근·카카오/네이버 지도·카카오 T·TVING 등과,
한국에서도 사용하는 YouTube·Instagram·Netflix·Gmail·ChatGPT 등의 글로벌 서비스를
포함한다. 이 목록은 편집 판단이며 MAU나 인지도 조사 결과, 국내 개발사 목록, 지원
확정 목록으로 표현하지 않는다. 확인 안 됨은 미지원 확정이 아니다.

장르별/유료 차트만으로 우선 그룹에 편입하지 않는다. 전체 무료 차트 앱은 관측에 따라
교체되지만 선정 앱은 차트에서 빠져도 우선 그룹에 남는다. 앱이 비공개·보관 처리되면 목록에
노출되지 않는다. 차트 자료는 수집된 관측 시점 기준이며 실시간 순위라고 표시하지 않는다.

신규 수집은 빠진 국내 주요 앱이나 공식 지원 근거가 확인된 후보를 우선한다. 카테고리별
차트로 등록 총수만 늘리는 작업을 기본 운영 목표로 삼지 않는다. 전문 앱도 통합 목록에서
발견하고 검색할 수 있다. 이 변경은 자동 수집 스케줄을 새로 만들거나 변경하지 않는다.

## 검색·정렬·통계

- 기본 진입과 검색은 같은 전체 공개 앱 목록을 사용한다. 이름·영문명·별칭 검색을 유지한다.
- 검색·분류·상태·정렬 변경 시 다른 조건은 유지하고 첫 페이지로 이동한다.
- 새 URL에는 `collection`을 넣지 않는다. 이전 `core/all` 링크는 통합 목록으로 해석한다.
  이전 `supported` 링크는 명시적인 유효 `status`가 없을 때만 `status=supported`로 해석하며,
  명시적인 `status=all`을 포함한 다른 상태·검색어·분류·정렬·페이지를 보존한다.
- 지원 상태 버튼은 모바일·데스크톱에서 검색 아래에 항상 표시한다. 카테고리는 사이드바와
  모바일 Dialog에서 선택한다. `unknown`은 “근거 미확인” / “Unconfirmed”으로 표시한다.
- 통계는 전체 공개 KR 앱 기준이다. 검색·분류·상태 필터로 분모를 바꾸지 않으며 검색·필터
  아래의 기본 접힘 영역에서 펼쳐 본다. 현재 검색 결과 수와 전역 통계를 구분한다.
- 차트 테이블이 없으면 편집 선정 여부·이름순으로 대체한다. 통합 목록의 범위는 줄이지 않는다.
- URL·언어·상세 복귀·브라우저 뒤로 가기와 모바일 필터를 유지한다.

## 이번 변경의 적용 범위

로컬 탐색 코드와 문서를 개선한다. DB 스키마·운영 데이터·권한·외부 프로젝트·배포는 변경하지
않으며, 기존 판정·근거·검토일을 보존한다. 구현과 검증 진행은 `specs/009-core-directory/tasks.md`,
실제 검사 결과는 `docs/verification.md`에 기록한다.

## 과거 운영 상태 — 2026-11-03

아래는 세 목록으로 운영하던 시점의 기록이며 이번 통합 탐색이 배포되었다는 의미가 아니다.

2026-11-03 읽기 전용 운영 조회에서 공개 앱 1,280개, 공식 지원 206개를 확인했다. 선정된
78개는 모두 기존 공개 앱이며 이 안에서 지원 13개·예정 1개·확인 안 됨 64개다.
운영의 `public.app_chart_rankings`는 아직 없으므로 이 스키마 상태에서는 기본 목록이
선정 78개로 동작하고 차트 자료 부재를 안내한다. 전체 목록과 지원 확인 목록은 각각
1,280개와 206개를 유지한다. 이 숫자는 해당 시점의 조회이며 고정된 UI 수치가 아니다.

코드는 차트 테이블이 있는 환경에서 무료 차트와 자동 합집합을 수행한다. 테이블이 없는
환경의 대체 동작도 격리 DB에서 검증했다. 운영 스키마·데이터·배포는 이 작업에서 변경하지
않았다. 로컬 구현 결과이며 운영 화면에 반영됐다고 주장하지 않는다.

명세·작업 목록은 `specs/009-core-directory`, 실제 검사 결과는 `docs/verification.md`에 기록한다.

### 후속 운영 반영

사용자의 커밋·푸시 요청에 따라 `e07bf72`를 main에 반영했다. 기존 Vercel Git 운영 배포의
READY·공식 도메인 연결을 확인했고, 실제 브라우저에서 기본 78개·지원 확인 206개·전체
1,280개와 전문 앱 전체 검색을 검증했다. 위의 배포 전 설명은 최초 로컬 구현 시점 기록이다.
운영 DB나 순위 스키마 변경은 없으며 기본 선정 78개 대체 동작으로 서비스한다.
